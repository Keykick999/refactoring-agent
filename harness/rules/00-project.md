# Project Rules

## Project

Java/Spring Boot 기반 Agent 시스템을 개발한다.

## Language

- Java 17
- Gradle
- Spring Boot

## Development Principles

- 단순한 설계를 우선한다.
- 필요하지 않은 추상화를 추가하지 않는다.
- 구현 전에 기존 구조와 책임을 확인한다.
- 하나의 클래스는 명확한 하나의 책임을 가진다.
- 기존 설계를 임의로 변경하지 않는다.
- 새로운 의존성을 추가하기 전에 필요성을 검토한다.

## Implementation

- 컴파일 가능한 상태를 유지한다.
- 기능을 구현하기 전에 관련 인터페이스와 책임을 확인한다.
- 구현 과정에서 불필요한 파일을 생성하지 않는다.
