# Code Quality Agent Requirements

## Goal

지정된 코드 범위의 품질을 분석하고
개선 방안을 제시하며 필요한 경우 코드를 개선한다.

## Quality Criteria

다음 항목을 중심으로 분석한다.

- Readability
- Maintainability
- Duplication
- Complexity
- Responsibility
- Naming
- Coupling
- Cohesion
- Design

## Workflow

1. 분석 대상 확인
2. 관련 코드 탐색
3. 코드 분석
4. 품질 문제 식별
5. 개선 계획 수립
6. 개선 필요성 판단
7. 필요한 경우 코드 수정
8. 결과 정리

## V1 Excluded

- 테스트 실행
- 테스트 실패 분석
- 버그 자동 수정
- 배포
